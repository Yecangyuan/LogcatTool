## 修复 PkgPicker 中 hjkl 干扰文本输入 bug

**问题**：按 `p` 打开包名选择器后，在搜索框输入时 `j/k` 等字符被全局 `KeyMap.Up/Down`（绑定了 `"up","k"` 和 `"down","j"`）拦截，导致无法向搜索框输入这些字母。

**修复位置**：`internal/model/update.go` `handlePkgPickerKey` 函数。

**修复方案**：新增包级别 `pkgPickerNavUp/pkgPickerNavDown` binding，仅绑定 `"up"/"down"` 纯方向键，在 `handlePkgPickerKey` 中替换原来的 `m.keys.Up/Down`（后者含 `j/k`）。打印字符仍通过 `default` 分支写入搜索框。

**安装**：`go install .` → `/Users/simley/go/bin/LogcatTool`（6.1MB，2026-06-02 11:37）
